# Brand Spec: Sintiens (Scientific Ethos / Academic Naturalism)

## Core Palette (OKLch)
- `--bg`:      oklch(98% 0.006 85)   /* Warm scholarly paper */
- `--surface`: oklch(99.5% 0.002 85) /* Pristine gallery surface */
- `--fg`:      oklch(15% 0.015 160)  /* Deep botanical charcoal */
- `--muted`:   oklch(48% 0.018 160)  /* Muted sage for notes */
- `--border`:  oklch(88% 0.01 160)   /* Hairline technical divider */
- `--accent`:  oklch(35% 0.06 155)   /* Forest Green primary */
- `--link`:    oklch(55% 0.12 210)   /* Scientific cyan for interactivity */

## Typography
- **Display (Editorial)**: `Playfair Display`. Large (72px+), tight tracking (-0.03em), high contrast.
- **Body (Narrative)**: `Hanken Grotesk`. Modern, high legibility, generous line-height (1.65).
- **Technical (Analytical)**: `JetBrains Mono`. For metadata, citations, and data.

## Visual Posture
- **Museum Layout**: Staggered, asymmetrical grids. Content is treated like "exhibits".
- **Hairline Precision**: 0.5px borders, no shadows. Depth via tonal layering (`--bg` vs `--surface`).
- **Glassmorphic Lens**: 20px backdrop-blur on navigators to simulate observing through glass.
- **Academic Restraint**: Single accent color used sparingly. Maximum negative space.
